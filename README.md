# Problem Solving with TypeScript & OOP

This repository contains my TypeScript assignment from Modules 1, 2, and 3 of Programming Hero Level-2 Batch-8. I solved eight programming problems using TypeScript and OOP concepts, and wrote two blogs about topics I learned.

## The solutions.ts file includes below functions:

1. multiplyValue() - Uses an optional multiplier, with 2 as the default when not provided.
2. processInput() - Uses union types and type narrowing to handle strings, numbers, and booleans.
3. formatCoordinate() - Formats a readonly tuple containing latitude, longitude, and a location name.
4. concatenateArrays() - Combines multiple arrays using generics and rest parameters.
5. getPopularCourses() - Filters published courses based on their student count.
6. pluckValues() - Extracts property values from objects using generics and keyof.
7. Employee and Manager - Demonstrates inheritance and `private`/`protected` access modifiers.
8. validateAgeAsync() - Uses a Promise and setTimeout to validate age asynchronously.
